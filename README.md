# Практикум по цифровым сервисам Актион

Пять учебных ситуаций для администратора обучения: приглашения, назначение программ, сверка данных по почте, электронный протокол и Монитор ЦОТ.

[Открыть тренажер](https://fatco321.github.io/tripteh-training/)

В репозитории размещена готовая статическая сборка. Все рабочие действия эмулируются в браузере: реальных писем, скачиваний и подписания документов нет. Состояние прохождения хранится в пределах вкладки.

## Встраивание

```html
<iframe
  src="https://fatco321.github.io/tripteh-training/"
  title="Практикум по цифровым сервисам Актион"
  style="width:100%;height:750px;border:0"
></iframe>
```

Тренажер сообщает родительской странице свою высоту через `postMessage`: `{ type: "tripteh:resize", height }`. Для автоматической высоты родительская страница должна проверять источник iframe и origin `https://fatco321.github.io`, затем устанавливать полученную высоту. Если платформа не обрабатывает сообщения, используется заданная высота iframe.
